# Sofiles

Sofiles est la personnalisation de Clover demandée par Sofiane Messaoudi, pour son usage dans l’Explorateur classique de Windows. Les onglets et les favoris sont les fonctions centrales. L’identité confirmée est Sofiles, son icône de dossier bleu et S blanc, et Sofiane Messaoudi pour les modifications.

Demandes confirmées : français, anglais, allemand ; contact so.messaoudi@gmail.com ; don PayPal facultatif de 20 CHF ; installateur ; notification et installation des mises à jour ; hébergement du projet sur GitHub.

Le moteur reste Clover 3.0.406. Il n’est pas une réécriture, ne prend pas encore en charge l’Explorateur moderne de Windows 11 et conserve les limites de sécurité documentées. La licence fournie interdit la redistribution modifiée. Le dépôt peut recevoir les nouveaux outils et leur documentation ; les binaires historiques restent hors du dépôt.

Choix d’implémentation : les réglages et l’installation suivent les conventions Windows, avec une fenêtre native et les trois mêmes langues. L’application ne facture pas son utilisation. Le lien PayPal ouvre seulement la page de don ; aucune donnée de carte ni transaction ne passe par Sofiles.

Hypothèses de cette itération : installation pour l’utilisateur courant ; vérification automatique des mises à jour facultative ; pas de démarrage automatique avec Windows ; conservation du profil et des favoris lors de la désinstallation.
