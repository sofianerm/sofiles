# Interface Sofiles

Cette extension conserve l’identité existante de Sofiles. Mode : Operate pour les réglages et l’installation, Read pour l’aide.

La fenêtre native Windows emploie Segoe UI 10 pt, les boutons, onglets, cases à cocher et dialogues Windows. L’icône existante reste l’unique marque. Fond clair système, texte système, accent bleu de l’icône ; le contraste et les états désactivés suivent Windows. Pas de nouveau logo ni d’illustration.

Les réglages regroupent langue, mises à jour, aide/contact et crédits. Le changement de langue explique que les fenêtres Sofiles doivent être fermées. Les notifications de mise à jour donnent la version et les changements avant le téléchargement. Les erreurs offrent une prochaine action et une référence de diagnostic.

Les textes allemands et les polices agrandies doivent rester lisibles : fenêtre redimensionnable, disposition automatique, boutons à taille automatique, libellés multiligne. Ordre de tabulation et touches d’accès natifs.
